VERSI GAMBAR SELALU TERLIHAT SAAT MENGISI

Perubahan: panel gambar memakai fixed positioning pada layar desktop agar tetap berada di tempat saat kolom jawaban di-scroll. Pada layar kecil, layout kembali normal supaya form tidak tertutup.

Cara pakai:
1. Ekstrak ZIP ke folder baru.
2. Buka CMD dari folder tersebut.
3. Jalankan:
   "C:\Users\ASUS\AppData\Local\Programs\Python\Python312\python.exe" -m streamlit run app.py

File kunci: kunci_jawaban.csv. Isi kunci yang sudah diverifikasi sebelum mengaktifkan anatomi_01 hingga anatomi_25.
Jika aplikasi lama masih aktif, hentikan dengan Ctrl+C di Command Prompt lalu jalankan versi baru dari folder ini.
